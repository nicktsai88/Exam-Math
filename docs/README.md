# 圓的解法實驗室

這是依 10 所學校、114 學年度上學期國三第二次段考製作的「圓」單元解析與自我測驗網站。

## 使用方式

1. 直接開啟 `index.html`。
2. 先從「同解法索引」選一種策略，再依學校或關鍵字篩選。
3. 解析模式可直接閱讀幾何直觀、逐步視覺化與答案；測驗模式會在首次作答後鎖定答案並顯示解析。
4. 進度、錯題與複習標記只儲存在目前瀏覽器，不會上傳姓名或作答資料。
5. 「列印目前篩選」可輸出題目與答案頁；列印時會切換至高解析題圖。

## 題庫結構

- 共 204 題，來源涵蓋七賢、五福、正興、民族、明華、復華、陽明、楠梓、福山、龍華。
- 依主要解題方式分成 10 類，排序固定為「解法 → 學校 → 原始題號」。
- 每題保留學校、原始題號、原卷頁碼與版本，並附原題裁圖。
- 每題都有「概念模型・非按比例」的幾何視覺化；真正數值與圖形關係仍以原卷題圖為準。

## 部署

本資料夾是純靜態網站，可直接部署到 GitHub Pages、Netlify 或一般靜態主機。GitHub Pages 請把本資料夾內容放在儲存庫根目錄。

### GitHub Pages（網頁操作）

1. 建立一個新的 GitHub repository。
2. 解壓縮 ZIP，將裡面的所有內容直接上傳到 repository 根目錄；確認 `index.html` 不在第二層資料夾中。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
6. 等待 GitHub 顯示公開網址後開啟即可。若更新內容，重新上傳並覆蓋同名檔案。
